# NEU-DET experiment

The official archive supplied 1,800 image and annotation pairs. The preparation audit removed three repeated boxes and excluded two records with identical decoded pixels and conflicting annotations. The seed-42 split contained 1,258 training images, 270 validation images, and 270 test images. The source archive SHA-256 was `cf04bb0b05d364f23e05031b191b20b908a0e5eb11466df74ee7fba98ec835d5`. [NEU-DET maintainers](https://faculty.neu.edu.cn/songkc/en/zdylm/263270/list/index.htm)

## Validation and model selection

Both runs used 96 × 96 inputs, eight epochs, batch size 32, seed 42, and the same split. Training ran on an Intel Core i5-9400F with Windows, CPython 3.14.7 and PyTorch 2.14.0+cpu. Pass `--size 96 --epochs 8 --batch-size 32 --seed 42` to both training commands in the README to reproduce these settings.

| Training variant | Validation mAP@50:95 | Validation AP@50 |
| --- | ---: | ---: |
| Baseline | 18.13% | 45.23% |
| Horizontal flips | 17.72% | 46.58% |

Flips improved AP@50 on validation while slightly reducing AP averaged across localization thresholds. The baseline was selected by the predefined mAP@50:95 criterion and evaluated once on the held-out test split. Its test mAP@50:95 was **18.12%** and AP@50 was **46.77%**.

## Test errors

The operating threshold was 0.25. Matching used class agreement and IoU ≥ 0.50.

| Defect | Annotated boxes | Recall | Unmatched predictions | Missed boxes |
| --- | ---: | ---: | ---: | ---: |
| Crazing | 104 | 62.50% | 224 | 39 |
| Inclusion | 170 | 54.71% | 651 | 77 |
| Patches | 134 | 85.07% | 177 | 20 |
| Pitted surface | 61 | 63.93% | 45 | 22 |
| Rolled-in scale | 93 | 66.67% | 215 | 31 |
| Scratches | 94 | 60.64% | 133 | 37 |

Inclusion had the most missed boxes and unmatched predictions at this threshold. The sample overlays also include an unmatched scratches prediction scored at 0.81. These results make class-specific precision/recall curves and examination of overlapping predictions useful follow-up experiments. `evaluate` generates marked examples alongside the local JSON report. These counts apply to annotated defect images from this benchmark.

## CPU runtime

The selected checkpoint and its ONNX export agreed within tolerance on 60 fixed test images. The maximum matching box coordinate difference was 0.000088 pixels. The timing includes preprocessing, inference, and decoding with NMS on one CPU thread after warm-up. Runtime versions were PyTorch 2.14.0+cpu and ONNX Runtime 1.32.0.

| Runtime | p50 | p95 |
| --- | ---: | ---: |
| PyTorch | 3.54 ms | 4.07 ms |
| ONNX Runtime | 1.62 ms | 1.96 ms |

The local ONNX model is `runs/detector.onnx`. Aggregate results and annotated samples are regenerated by the CLI, with the dataset, trained weights, and image overlays kept in Git-ignored folders.
